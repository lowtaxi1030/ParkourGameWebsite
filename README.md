# ParkourGameWebsite

2D 橫向跑酷遊戲與關卡編輯器的第一版專案骨架。

## 功能規劃

- 2D 橫向跑酷遊戲
- 混合式關卡編輯：格線吸附與自由放置
- JSON 關卡檔案
- SQLite 儲存關卡索引與遊玩紀錄
- 關卡編輯器與遊戲共用關卡資料格式
- 編輯器可直接調整選取物件的位置與大小
- 關卡 JSON 匯入與匯出
- 不儲存即可測試目前編輯中的關卡
- 手機觸控方向與跳躍按鈕
- 後端檢查關卡設定、物件種類、物件 ID 與物件範圍

## 執行方式

需要 Python 3.10 或更新版本。

1. 建立並啟用虛擬環境（建議）。
2. 安裝套件：

   ```bash
   pip install -r requirements.txt
   ```

3. 啟動網站：

   ```bash
   python run.py
   ```

4. 在瀏覽器開啟終端機顯示的本機網址，通常是 `http://127.0.0.1:5000`。

## 資料位置

- `levels/examples/`：範例關卡
- `levels/user/`：使用者建立的關卡
- `instance/game.db`：本機 SQLite 資料庫（啟動時自動建立）

## 目前版本

目前已包含可遊玩的基礎關卡流程：

- 範例關卡與使用者關卡瀏覽、載入及遊玩
- 左右移動、跳躍、平台碰撞、尖刺與終點判定
- 編輯器物件放置、選取、移動、調整大小、刪除、Undo／Redo
- 右側物件屬性面板，可直接修改 X、Y、寬度與高度
- 關卡 JSON 匯入與匯出
- 不必先儲存即可測試編輯中的關卡
- 電腦鍵盤與手機觸控操作
- 關卡儲存為 JSON 檔案，並由後端檢查資料格式與物件範圍
- 後端關卡與資料庫基礎自動化測試
